# 💬 ChatOverhead

Лёгкий плагин для Paper, который отображает сообщения игроков над их головами.

## ✨ Возможности

- **Сообщения над головой** - Сообщения остаются привязанными к голове игрока
- **Плавные анимации** - Предыдущие сообщения плавно поднимаются вверх
- **Поддержка нескольких строк** - Высота анимации зависит от длины сообщения
- **Поддержка MiniMessage** - Градиенты и форматирование текста
- **Настройка** - Время отображения, высота, длина сообщения и многое другое
- **Список игроков** - Выбор игроков, которые могут использовать сообщения над головой

## ⚙️ Конфигурация

```yaml
lang: ru_ru.yml

settings:
  text-height: 2.4
  display-seconds: 8
  max-text-length: 50
  use-minimessage: true

allowed-players:
  - []
```

## 🛠️ Команды

```text
/chatoverhead add <player>
/chatoverhead remove <player>
/chatoverhead list
/chatoverhead reload
```

## 🌍 Языки

В комплекте:

- 🇷🇺 Русский
- 🇺🇸 Английский

Пользовательские языки можно добавить через папку `lang/`.
